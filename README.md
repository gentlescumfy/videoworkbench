# Video Workbench

本地视频创作工作室，包含 tldraw 自由画布、剧情故事制作流程、角色与场景设计、分镜、视频与音频任务、资产库和剪辑时间线。界面参考 OiiOii；服务端使用 Express 和 SQLite。

## 启动

需要 Node.js 22.13 或更新版本。

```bash
npm ci
cp .env.example .env
npm run dev
```

打开 `http://localhost:5173`。生成服务的配置见 `.env.example`；没有配置时仍可浏览画布和已有项目。

画布使用 tldraw 的自定义形状承载制作卡片与素材卡片。自由画布可拖动、缩放、创建和连接节点，支持小地图、适应内容和撤销/重做；制作卡片位置保存在本机浏览器。部署到公网时，需要设置 `VITE_TLDRAW_LICENSE_KEY`。tldraw [官方许可说明](https://tldraw.dev/sdk-features/license-key)指出，本地开发不需要密钥，生产环境需要有效许可。

```bash
npm run build
npm test
```

## 凡骨逆天项目对照

对照项目：<https://www.oiioii.tv/space/a6b13e5a-7988-401a-b7c9-8ae54e82ee44>。

截至 2026-09-28，已核对原项目的剧本、7 个角色、10 个场景、28 个分镜，以及资源面板中的 59 张图片和 5 段视频。原项目停在分镜视频审核阶段：前 5 个视频已生成，其余 23 个待生成。当前本地实例已导入这些内容，可在 `http://localhost:5173/space/a6b13e5a-7988-401a-b7c9-8ae54e82ee44` 查看。

对照方式：用 Chrome 电脑操作检查原站画布、节点详情、对话和资源面板；用本地 API 检查结构化数据，再通过浏览器逐项核对布局和交互。`scripts/import-reference-project.mjs` 用于导入经用户授权取得的原项目数据，`scripts/acquire-reference-assets.py` 用于取得该项目资源。导入命令：

```bash
python3 scripts/acquire-reference-assets.py
node scripts/import-reference-project.mjs
```

上述脚本需要本机的 `reference/project.json`、`reference/assets.json`，以及取得资源所需的原站访问权限。这两个文件、下载素材和本地数据库均不上传到公开仓库。

已从原站节点补录全部 7 个角色设定与主图提示词、3 个三视图提示词、1 个表情图提示词、10 个场景的主图/多视角提示词、28 个分镜图提示词和前 5 个视频的完整提示词。`scripts/apply-reference-prompts.mjs` 可把经浏览器核对的 `artifacts/reference-node-prompts.json` 合并到参考数据与已有项目，保留媒体、任务与制作设置；导入时保留各角色原有的产物数量。分镜区按原站七列竖卡布局展示，通过卡片顶部切换分镜图与视频。

## 制作链路

制作流程逐阶段确认：剧本 → 角色与场景设定 → 选角/三视图/表情图/场景多视角 → 分镜 → 分镜图 → 视频/音效/台词提示词 → 镜头视频 → 背景音乐 → 成片。角色主图默认 4:3，场景与三视图 16:9，表情图 3:4，各项可保留原站的独立规格。图片变体引用主图或已补录的专用参考图；分镜图引用角色与场景图；视频任务携带分镜图和角色、场景参考图，并按提示词中的 `@图N` 编号对应素材。媒体结果下载到本地后写回对应卡片。合成保留镜头原声，并可混入背景音乐，输出项目设定的画面比例。“单独生成镜头音效与配音”是本地补充的可选阶段，默认关闭，开启后在视频与音乐阶段之间执行。

原项目指定 `minimax-h3-max`，但当前本地已配置的数据源只有 AgnesAI 模型。界面会提示模型不匹配，并允许在全局 Agent 配置中接入原模型，或明确选择已有模型。切换模型可能改变画面和时长，例如 Agnes Video 2.5 最长 12 秒，而原项目镜头为 15 秒。程序不会自动改用替代模型，也不会自动提交剩余 23 个视频任务。制作 API 与本地模拟服务已通过测试；真实提供方的请求仍需在选定模型后逐项验证。

Agnes Video 2.5 使用 `keyframe` 或 `reference` 模式，二者互斥；参考图编号会转换为 `<Picture N>`。依据 [Agnes 官方模型说明](https://github.com/AgnesAI-Labs/skills/blob/main/agnes-ai-models/references/model_catalog.md)，单段为 4–12 秒。其[视频文档](https://agnes-ai.com/en/docs/agnes-video-25-flash)还要求公开可访问的媒体 URL。本地图片不会伪装成公网地址：生成结果保留提供方原始 URL 供后续请求使用；自行托管图片时配置 `GENERATION_MEDIA_BASE_URL`。不支持的时长、素材数量或本机地址会在提交请求前报错。

目前复刻的是可见项目数据、tldraw 画布和可执行制作链路，并非原站内部实现。剩余差异包括完整历史对话、节点细节与编辑交互，以及原模型的真实生成验证。32 项测试通过，包含实际 FFmpeg 音画合成；构建通过。


## 角色图片节点弹窗（2026-09-28）

点击角色的选角、三视图或表情图后，会选中对应图片、居中画布并收起全局聊天。图片上方显示派生、智能编辑、编辑、重新生成、下载；下方是 680×483 的提示词浮层，切换 Agent 对话后为 680×270。提示词、图片参数和参考图按每张素材分别保存。切换图片时自动保存排队提交，版本冲突仅对无收费的编辑重试；未保存草稿保留在本机，避免丢失编辑。参数面板的比例与生成数量禁用状态沿用原站；裁剪及旋转/镜像使用图片下方操作条，裁剪可选择比例并拖动裁剪区域。

单张重新生成使用 `/api/projects/:id/production/assets/generate`，保留制作阶段和其他成果。重复提交、服务重启、提供方失败以及生成期间用户修改素材均有保护与测试；发生编辑冲突时保留用户修改和生成结果供查看。原站 Oii Image 模型未接入，本地不会自动替换成 Agnes 或发起收费请求。二次确认设置可保存；当前接口无法预估积分，因此仍要求确认。透明背景与非标准质量尚未连接到 OpenAI 图片协议，会在发送前明确拒绝，而不会静默忽略。

当前按原站已观察界面实现布局和菜单。原站完整模板库、各 AI 编辑工具的专用服务和富文本引用行为仍有差异；智能编辑目前通过标记参考图与文字要求调用已配置图片模型，尚未接入专用蒙版编辑接口。浏览器已验证提示词保存和恢复、三视图参数隔离、参数菜单、二次确认面板的输入焦点、1:1 裁剪区域拖动、旋转保存回写、智能编辑标记及撤销/重做、预览缩放与 Escape 返回。旋转测试后已还原原图。画布背景按原站采用纯黑和 20 像素点阵；尚不能标记为全部一模一样。

角色 Agent 对话会提交当前图片、所选参考图和前几轮对话；OpenAI 兼容聊天协议按[官方多模态消息格式](https://developers.openai.com/api/reference/resources/chat)发送图片，纯文本提示词优化保持文本请求。已通过协议测试，尚未发起收费的提供方实测。
